## What This Is

A read-only, multi-sport (tennis + NBA + WNBA) Kalshi opportunity engine that surfaces executable pricing
inconsistencies + dutch-book arbitrage as buy-only opportunities. Two surfaces: the original **Streamlit
per-sport dashboard** (`streamlit run app.py`) and a new **FastAPI REST API + cross-sport NiceGUI
opportunity-first dashboard** (`python serve.py`). A pure engine (fetch → consistency/dutch-book →
cross-sport scanner → SQLite snapshot store → lifecycle diffs) gives every opportunity a stable id and a
persisted history; the API/NiceGUI read the latest snapshot. Canonical docs: `docs/PROJECT_BRIEF_OVERVIEW.md`
(brief) + `docs/TECHNICAL_DOCUMENTATION.md` (deep).
